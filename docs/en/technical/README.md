# Technical documentation

How Web Service Manager is built: what it models, what it must do, how it is analysed and designed, and where each part lives in the code. It follows the RUP method and was written from the code; every diagram is a PlantUML source with its rendered SVG next to it, drawn with the colours of Didactika.

| Discipline | Purpose |
| --- | --- |
| [Domain model](./domain/README.md) | The business concepts, ordered by importance, and the rules between them. |
| [Requirements](./requirements/README.md) | Actors, requirements and the specification of each use case. |
| [Analysis](./analysis/README.md) | Analysis classes and how they collaborate in each use case. |
| [Design](./design/README.md) | Design classes, data model, components and sequences. |
| [Implementation](./implementation/README.md) | The code map and the code and tests of each use case. |
