Web Service Manager (`local_servicemanager`) configura servicios web de Moodle a partir de un único archivo YAML. Usted escribe lo que necesita un servicio, las funciones que llama y, si lo desea, lo que puede hacer su rol, y el plugin crea el usuario del servicio, el rol, las capacidades, el servicio externo y el token, y los mantiene al día con el archivo cada vez que lo cambia.

<Screenshot src="asset:dashboard.webp" alt="El panel, con la salud de los esquemas y la lista de esquemas" caption="El panel: el estado de los servicios web, la salud de cada esquema y las acciones de la lista." url="/local/servicemanager/index.php" />

Cada esquema es una sala cerrada para un consumidor: su propio usuario, su propio rol, su propio servicio y su propio token. Un token filtrado, o un consumidor que se comporta mal, solo alcanza lo que su esquema declara. Deshabilitar o eliminar el esquema cierra la sala.

## Qué hace

<FeatureGrid>
  <Feature icon="description-rounded" title="Un archivo, un servicio">El usuario, el rol, las capacidades, el servicio y el token salen de un esquema YAML, y el plugin lee de Moodle las capacidades que necesita cada función.</Feature>
  <Feature icon="history-rounded" title="Versiones y retroceso">Cada cambio de la definición se conserva, se puede comparar línea a línea y se puede deshacer.</Feature>
  <Feature icon="monitor-heart-rounded" title="Comprobaciones de salud">Una tarea programada comprueba que lo que creó cada esquema sigue ahí y funciona, y avisa por correo.</Feature>
  <Feature icon="swap-horiz-rounded" title="Importar y exportar">Mueva esquemas entre sitios y entornos como archivos o como un único archivo comprimido.</Feature>
  <Feature icon="api-rounded" title="Servicios web propios">Cree y actualice esquemas desde scripts y canalizaciones, sin la interfaz.</Feature>
  <Feature icon="dark-mode-rounded" title="Sigue el tema">En Moodle 5.3 las páginas siguen el modo de color del sitio, también el oscuro.</Feature>
</FeatureGrid>
